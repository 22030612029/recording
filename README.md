# 砚台 · 考研学习管理台

面向 2027 考研备考的个人学习管理 Web 应用：刷题记录、错题与知识点、目标差距与学情分析。数据全部保存在浏览器本地（localStorage），支持一键导入/导出 JSON 备份。

## 功能

- **仪表盘**：目标院校与分科差距一目了然，试卷/得分率/错题统计、最近试卷速览
- **刷题记录**：按科目筛选，录入每次模考/真题成绩，支持 ±1/5 分快速微调与等级徽章
- **错题与知识点**：错题本与知识点双标签管理，支持按科目/模块/错因筛选；可上传题目截图（自动压缩存为 base64）并关联知识点
- **学情分析**：加权得分率、各科差距、生成可复制的复习建议报告
- **数据与设置**：目标院校管理、科目管理、得分率口径调整、数据导入/导出/清空

## 技术栈

- 原生 HTML + CSS + JavaScript（ES Modules），无构建依赖
- [ECharts 5](https://echarts.apache.org/) 数据可视化
- 本地持久化：localStorage（`kaoyan_study_data`）
- 中式"砚台"视觉：墨蓝 × 暖米白 × 学院金

## 本地运行

```bash
# 任选其一，然后在浏览器打开 http://localhost:8731/index.html
python -m http.server 8731
# 或
npx serve .
```

> 直接双击打开 `index.html` 也可使用（模块加载在部分浏览器下建议通过本地服务器访问）。

## 数据说明

- 所有数据仅存于本机浏览器，清除站点数据会丢失记录，请定期在「数据与设置」页导出备份。
- 「加载示例数据」会用内置示例（含北大计算机目标院校）替换当前数据，仅供体验。
