# 砚台 · 考研学习管理台

面向 2027 考研备考的个人学习管理 Web 应用：刷题记录、错题与知识点、目标差距与学情分析。支持**多账号**（注册/登录，每个账号数据独立），数据保存在浏览器本地（localStorage），可一键导入/导出 JSON 备份。

## 功能

- **多账号**：注册自定义 ID 与密码，各账号学习数据互不干扰，可随时退出/切换；支持**修改密码**、登录时**记住上次 ID**
- **仪表盘**：目标院校与分科差距一目了然，试卷/得分率/错题统计、最近试卷速览
- **刷题记录**：按科目筛选，录入每次模考/真题成绩，支持 ±1/5 分快速微调与等级徽章；**选科目自动填满分**（数学/408=150，政治/英语=100）
- **错题与知识点**：错题本与知识点双标签管理，支持按科目/模块/错因筛选、知识点按**掌握度排序**；可上传题目截图（自动压缩存为 base64）并关联知识点
- **知识库**：多级目录 + Markdown 笔记（内置编辑器：分屏实时预览、工具栏、自动保存、记录创建/更新时间、按标题/内容搜索、可插入图片）；支持 **LaTeX 数学公式**（行内 `$...$` 与块级 `$$...$$`，内置 KaTeX 离线渲染）
- **学情分析**：加权得分率、各科差距、生成可复制的复习建议报告（未刷卷科目始终标记为高优先级）
- **数据与设置**：目标院校管理、科目管理、得分率口径调整、数据导入/导出/清空、**存储占用预警**（接近 5MB 上限时提示）、账号管理

## 技术栈

- 原生 HTML + CSS + JavaScript（ES Modules），无构建依赖
- [ECharts 5](https://echarts.apache.org/) 数据可视化
- 本地持久化：localStorage（`kaoyan_users` 账号表 / `kaoyan_study_data_<userId>` 用户数据），密码加盐 SHA-256 哈希
- 中式"砚台"视觉：墨蓝 × 暖米白 × 学院金

## 本地运行

```bash
# 任选其一，然后在浏览器打开 http://localhost:8731/index.html
python -m http.server 8731
# 或
npx serve .
```

> 直接双击打开 `index.html` 也可使用（模块加载在部分浏览器下建议通过本地服务器访问）。

## 数据说明

- 所有数据仅存于本机浏览器，清除站点数据会丢失记录，请定期在「数据与设置」页导出备份。
- 「加载示例数据」会用内置示例（含北大计算机目标院校）替换当前数据，仅供体验。
